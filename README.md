# Instruction Set Architecture (ISA) Comparison

## Overview
An academic research project comparing four major Instruction Set Architectures: **RISC-V, x86-64, MIPS, and ARM**.

The research explores architectural design principles, instruction-set characteristics, performance considerations, and trade-offs across different computing environments.

## Research Topics
- RISC vs. CISC design philosophies
- Instruction set complexity and extensibility
- Performance and efficiency considerations
- Compatibility and software ecosystems
- Applications in modern computing systems

## My Contribution
Conducted the primary research and comparative analysis, contributed to the technical writing, and helped prepare the final report as part of a university group project.

## Academic Context
Completed as part of Computer Architecture coursework during a visiting semester at the University of Jordan.
